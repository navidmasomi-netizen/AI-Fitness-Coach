# 13 — Component System

## Layered Intelligence

Components reveal information in levels: summary, context, recommendation and optional detail.

### Core patterns

- Health-score card: score + status + primary drivers
- Workout card: activity + duration/intensity + adaptive explanation
- Insight card: finding + evidence + recommended next step
- Progress module: trend + comparison + readable interpretation
- Status chip: icon + label; semantic color only when relevant
- Primary button: one dominant action per surface

Cards use 16 px radius; insight overlays use 18 px. Avoid placing more than one elevated insight layer over a base card. Copy should state why a recommendation changed.
