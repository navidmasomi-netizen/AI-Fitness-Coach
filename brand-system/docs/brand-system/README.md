# RUNPUY Brand System

This folder is the decision record for RUNPUY. Files 01–05 capture the strategic foundation; 06–14 define production rules; 15 is the asset register; 16 is the release audit.

Only assets outside `assets/brand/archive/` are approved for product use. When a rule and an exploratory image conflict, the written rule and approved master assets take precedence.

## Principles

1. **Useful intelligence, not visual noise.** Data must help a person decide or act.
2. **Health trust before fitness hype.** The system feels credible, calm and precise.
3. **Motion with control.** Energy appears through pacing, progress and angular detail—not decoration.
4. **Accessible by default.** Meaning is never carried by color alone.
5. **One system across languages.** Manrope and Vazirmatn share hierarchy and rhythm.
