# 08 — Typography

## Families

- Latin: **Manrope**
- Persian/Arabic: **Vazirmatn**

Both are product typefaces, not replacements for the custom logo artwork. Use tabular numerals for metric comparisons when supported.

## Scale

| Style | Size / line height | Weight |
|---|---|---:|
| Display | 32 / 40 | 700 |
| Heading | 24 / 32 | 650 |
| Title | 18 / 26 | 650 |
| Body | 16 / 24 | 400 |
| Caption | 14 / 20 | 400 |

For Persian, preserve the same hierarchy but allow extra vertical breathing room when diacritics or dense joins require it. Avoid artificial letter spacing in Persian. Interface numbers may remain Latin only when required by product conventions.
