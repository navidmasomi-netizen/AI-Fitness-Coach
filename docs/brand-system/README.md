# AI-Fitness-Coach V2 — Product Brand System

This directory is the source of truth for the V2 product brand system.

The V2 UI/UX redesign must derive from the approved decisions documented here. Designers, engineers, AI agents, and reviewers should not invent visual or verbal brand decisions outside this system unless the relevant document is explicitly updated.

## System Layers

1. Brand Discovery
2. Market & Competitor Brand Audit
3. Brand Core & Positioning
4. Creative Direction
5. Visual Identity
6. Product Design Foundations
7. Accessibility, Themes & States
8. Design Tokens & Component Rules
9. V2 Migration & QA

## Documentation Rules

- Approved decisions are version-controlled in GitHub.
- Each completed phase should be committed independently.
- Brand decisions must be usable by both design and engineering.
- Accessibility is a system constraint, not a final QA step.
- Existing V1 UI is not automatically authoritative for V2.
