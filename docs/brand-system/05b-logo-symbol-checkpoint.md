# Phase 5B — RUNPUY Visual Identity Checkpoint

**Updated:** 2026-09-21
**Status:** In progress — working direction selected, not final production artwork.
**Source:** User decisions in the RUNPUY brand-design conversation.

## Confirmed Direction

- Master brand: **RUNPUY**.
- The user preferred **C — Precision Wordmark** over the A and B logo explorations.
- Within C, three variations were explored: C1 softer, C2 sharper, C3 balanced.
- **C3 remains the current working direction** for the wordmark and app icon. It is being retained provisionally while the remaining brand-system phases progress.
- Athlete/bodybuilder integrations explored inside the R were rejected. The current working icon returns to the clean C3 R.
- Preserve the approved strategy in [Creative Direction](04-creative-direction.md): Future Self Movement, Scientific Precision, and Premium Restraint.

The logo exploration labels A/B/C are separate from the A/B/C tone architecture in Phase 04. Choosing logo C does not replace the default Balanced Human Intelligence product tone.

## Logo and App Icon Roles

- Full RUNPUY wordmark: primary brand name treatment.
- Stylized R within a rounded-square presentation: proposed app-icon direction.
- Inverse wordmark: dark-background usage demonstration.
- The entire C3 presentation board is **not** an app icon.
- Final geometry, spacing, minimum sizes, clear space, and export specifications remain to be approved.
- Concept previews are not production vector masters; this checkpoint does not include or claim delivery of image or SVG assets.

## Working Color Direction — Provisional

The following palette is retained as the working direction while the rest of the brand system is developed:

- Charcoal Black — `#151718`
- Warm White — `#F7F7F4`
- Light Gray — `#D9DCDE`
- Deep Navy — `#183A5A`
- Mineral Teal — `#2A8C78`

Current usage intent:

- Black, warm white, and light gray form the dominant neutral foundation.
- Deep navy supports scientific trust, information hierarchy, and premium technology.
- Mineral teal is a restrained health/progress accent.

This is a provisional working selection, not final palette approval. Exact usage ratios, semantic tokens, accessibility pairs, light/dark behavior, and production specifications remain to be validated.

4. Prepare vector masters, light/dark/monochrome variants, small-size checks, and usage rules.
