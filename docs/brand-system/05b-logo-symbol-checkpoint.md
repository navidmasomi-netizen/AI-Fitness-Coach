# Phase 5B — RUNPUY Visual Identity Checkpoint

**Updated:** 2026-09-17
**Status:** In progress — selected direction, not production-ready artwork.
**Source:** User decisions in the RUNPUY brand-design conversation.

## Confirmed Direction

- Master brand: **RUNPUY**.
- The user preferred **C — Precision Wordmark** over the A and B logo explorations.
- Within C, three variations were explored: C1 softer, C2 sharper, C3 balanced.
- **C3 is the current refinement target**: the user requested a preview using the previously selected brand palette. This is not final approval of the logo or app icon.
- Preserve the approved strategy in [Creative Direction](04-creative-direction.md): Future Self Movement, Scientific Precision, and Premium Restraint.

The logo exploration labels A/B/C are separate from the A/B/C tone architecture in Phase 04. Choosing logo C does not replace the default Balanced Human Intelligence product tone.

## Logo and App Icon Roles

- Full RUNPUY wordmark: primary brand name treatment.
- Stylized R within a rounded-square presentation: proposed app-icon direction.
- Inverse wordmark: dark-background usage demonstration.
- The entire C3 presentation board is **not** an app icon.
- Final geometry, spacing, minimum sizes, clear space, and export specifications remain to be approved.
- Concept previews are not production vector masters; this checkpoint does not include or claim delivery of image or SVG assets.

## Color Reconciliation — Open

The user reports that the palette was previously selected and finalized. The reviewed repository documents specify color behavior, but do not provide exact HEX/RGB values or a complete semantic token mapping.

This is a documentation/retrieval gap, **not a decision to discard or redesign the user's selected palette**.

Until the original palette is recovered and recorded:

- Do not invent HEX values or describe exploratory hues as approved.
- Do not extract incidental preview colors and promote them to approved tokens.
- Preserve the existing requirements: deep premium surfaces, meaningful accents, and restrained semantic color use.
- A recolored C3 cannot be described as matching the approved palette without that source.

## Next Steps

1. Recover and record the exact selected palette with its source and approval status.
2. Preview C3 using that palette while preserving its design direction.
3. Obtain explicit approval of the wordmark and app icon separately.
4. Prepare vector masters, light/dark/monochrome variants, small-size checks, and usage rules.
5. Define product tokens and verify accessibility before V2 implementation.

## Continuity Rule

Record subsequent approved brand decisions under `docs/brand-system/`, update the README status, and distinguish approved decisions from proposals and unresolved items. Do not change application code as part of documentation-only brand updates.
