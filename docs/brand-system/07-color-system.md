# 07 — Color System

## Primitives

| Token | Hex | Role |
|---|---:|---|
| Warm White | `#F7F7F4` | primary canvas |
| Ink | `#111719` | primary text and logo |
| Night Ink | `#0D1417` | dark canvas |
| Deep Navy | `#163A52` | trust, depth, secondary brand field |
| Emerald | `#18B887` | primary action and progress |
| Pale Mint | `#E6F6EF` | soft health surface |
| Light Gray | `#E5E7EB` | borders and dividers |
| Muted | `#667085` | secondary text on light surfaces |

## Semantic colors

Success `#18865F`; Warning `#B86A08`; Error `#D93F4C`; Information and focus `#2563EB`.

Emerald is brand/action color; semantic Success is darker so state meaning remains distinguishable. Warning, error and information are reserved for meaning, not decoration.

## Themes

Light theme uses Warm White canvas, white cards and Ink text. Dark theme uses Night Ink canvas, `#13232A` cards, Warm White text and `#A9B5BC` secondary text. Theme-specific values live in the token files.
